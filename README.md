## 💡 فكرة التطبيق

يهدف تطبيق **Lexis (ليكسيس)** إلى جمع كل ما يحتاجه متعلم اللغة الإنجليزية — من المستوى المبتدئ **A1** حتى المتقدم **C1** — داخل تجربة عربية أنيقة، مرتبة، وخالية من التزاحم البصري. يدمج التطبيق بين **قاعدة بيانات محلية فائقة السرعة (Room)** للعمل الفوري دون تأخير، و**المزامنة السحابية الآمنة (Cloud Firestore + Google Sign-In)** لحفظ تقدمك عبر أجهزتك، و**الذكاء الاصطناعي التوليدي (Firebase AI Logic / Gemini)** لإثراء المعاني وتوليد القصص والمحادثات المتدرجة عند الطلب.

| **4. مركز الاختبارات المتدرجة** | **5 أنماط تفاعلية** (اختيار من متعدد، إملاء واستماع، إكمال الجملة السياقية Cloze، مطابقة المعاني، وترتيب حروف الكلمة) عبر **3 مستويات صعوبة** (مبتدئ، متوسط، متقدم)، مع **تحكم كامل بمؤقت السؤال** (بدون مؤقت أو 10–60 ثانية + إيقاف مؤقت) وشاشة **مراجعة تفصيلية للإجابات**. |
| **5. موسوعة القواعد و1,244 فعلاً** | **35 درس قواعد** شاملة من **A1 إلى C1** (الشرح العربي المفصل، الصيغة التركيبية، الأخطاء الشائعة، 4 أمثلة صوتية، واختبار لكل قاعدة) + جدول شامل لـ **1,244 فعلاً** (141 فعلاً شاذاً + 1,103 فعلاً قياسياً) بتصاريفها الثلاثة (**V1 / V2 / V3**) ونطق وأمثلة لكل تصريف. |
| **6. مكتبة 500 قصة و500 محادثة** | **500 قصة متدرجة** (100 قصة لكل مستوى A1–C1) مع قراءة ثنائية اللغة ونطق لكل سطر واختبار من **10 أسئلة متعددة الأنماط** لكل قصة، بالإضافة إلى **500 محادثة استماع** (4–15 دقيقة حسب المستوى) بين شخصين عبر **22 شخصية صوتية** (رجال، نساء، أطفال بلهجات US وUK) مع التحكم بسرعة الصوت ووضع **التظليل والتكرار (Shadowing)**. |
| **7. لوحة الإحصائيات الشاملة** | تتبّع سلسلة الأيام المتواصلة (**Streak**)، دقائق الدراسة اليومية مقارنة بهدفك اليومي، عدد الكلمات المتقنة وقيد التعلم والمفضلة، توزيع مستويات **CEFR**، متوسط درجات الاختبارات، رسم بياني للنشاط اليومي، وتبديل المظهر (**نهاري / ليلي / تلقائي**) ولغة الواجهة (**عربي RTL / إنجليزي LTR**). |

## 📱 طريقة استخدام التطبيق

1. **تسجيل الدخول والمزامنة**: عند فتح التطبيق لأول مرة، سجّل دخولك عبر **حساب Google** لحفظ مفضلتك وإحصائياتك وتقدمك السحابي تلقائياً.
2. **تبويب «الإحصائيات» (الرئيسية)**: راقب تقدمك اليومي، اختر مستواك المستهدف (`A1`–`C1`)، أو افتح زر الإعدادات لتغيير المظهر والهدف اليومي ولغة الواجهة.
3. **تبويب «القاموس»**: ابحث بالعربية أو الإنجليزية، صفِّ حسب المستوى أو المفضلة، استمع للنطق **US/UK** مباشرة من القائمة، أو افتح أي بطاقة لاستعراض جميع أنواعها النحوية وأمثلتها وإثرائها عبر الذكاء الاصطناعي.
4. **تبويب «التدريب»**: تنقّل بين **البطاقات الذكية** (الذاكرة البصرية والسمعية) و**مركز الاختبارات** (اختر النمط ومستوى الصعوبة والمؤقت ثم راجع إجاباتك في النهاية).
5. **تبويب «القواعد»**: تصفّح دروس القواعد المتدرجة وأجرِ اختبار كل قاعدة، أو انتقل إلى قسم **1,244 فعلاً** للاستماع لتصاريف كل فعل (`V1 / V2 / V3`).
6. **تبويب «المكتبة»**: اختر من بين **500 قصة** (مع اختبار 10 أسئلة) أو **500 محادثة صوتية** مع فلترة المتحدثين الـ 22 وتفعيل وضع التظليل لتكرار الجمل خلف المتحدث.

## 📥 طرق تنزيل التطبيق وتثبيته على الهاتف

### الطريقة 1: الحصول على ملف APK جاهز مباشرة عبر GitHub Actions (دون كمبيوتر)

يحتوي المستودع على قالب بناء سحابي جاهز باسم `build-apk-workflow.yml` يقوم ببناء ملف **`Lexis-Android.apk`** وتوقيعه تلقائياً:

1. من صفحة المستودع على GitHub، اضغط **Add file ← Create new file**.
2. اكتب اسم المسار التالي بالضبط:
   ```text
   .github/workflows/build-apk.yml
   ```
3. انسخ محتوى ملف `build-apk-workflow.yml` الموجود في المستودع والصقه داخل الملف الجديد، ثم اضغط **Commit changes**.
4. انتظر نحو دقيقتين حتى يكتمل البناء في تبويب **Actions**، ثم افتح قسم **Releases** في المستودع وحمّل ملف **`Lexis-Android.apk`** مباشرة إلى هاتفك.

### تثبيت ملف الـ APK على هاتف Android
1. افتح ملف **`Lexis-Android.apk`** من مدير الملفات أو قائمة التنزيلات في الهاتف.
2. عند ظهور تنبيه الحماية، فعّل خيار **«السماح بتثبيت التطبيقات من هذا المصدر»**.
3. إذا ظهر تحذير من **Google Play Protect** (أمر طبيعي للتطبيقات المثبتة خارج المتجر)، اضغط **«مزيد من التفاصيل (More details)»** ثم **«التثبيت على أي حال (Install anyway)»**.

---

### الطريقة 2: البناء والتشغيل المحلي عبر Android Studio

#### المتطلبات
- **Android Studio** (إصدار حديث يدعم AGP 9.x وJDK 17+)
- **JDK 17**
- هاتف Android (بإصدار **Android 7.0 / API 24** فأعلى) أو محاكي Android

#### خطوات التشغيل
```bash
# 1. استنساخ المستودع
git clone <رابط-المستودع>
cd <اسم-المجلد>

# 2. استعادة مفتاح التوقيع التجريبي (لضمان عمل Google Sign-In مع إعدادات Firebase الحالية)
base64 -d debug.keystore.base64 > debug.keystore

# 3. بناء ملف APK للتثبيت
gradle :app:assembleDebug
```
بعد اكتمال البناء، ستجد ملف التطبيق الجاهز للتثبيت في المسار:
```text
app/build/outputs/apk/debug/app-debug.apk
```
كما يمكنك فتح المشروع مباشرة في **Android Studio** والضغط على **Run ▶** لتثبيته فوراً على هاتفك المتصل بكابل USB.

## 🛠️ التقنيات المستخدمة

- **اللغة وواجهة المستخدم**: Kotlin · Jetpack Compose · Material Design 3 · Edge-to-Edge · دعم كامل لاتجاهي **RTL / LTR** والوضع الليلي والنهاري.
- **الخطوط المدمجة**: Cairo (للنصوص العربية) · Plus Jakarta Sans (للإنجليزية) · JetBrains Mono (للرموز الصوتية IPA).
- **التخزين المحلي**: Room Database (قاعدة بيانات محلية للـ 4,949 كلمة و1,244 فعلاً و35 درس قواعد و500 قصة و500 محادثة و22 شخصية صوتية) + Jetpack DataStore للتفضيلات.
- **السحابة والذكاء الاصطناعي**: Firebase Authentication (Google Sign-In عبر Jetpack Credential Manager) · Cloud Firestore مع قواعد أمان صارمة (`firestore.rules`) · Firebase AI Logic (`gemini-3.8-flash`) مع App Check.
- **المحرك الصوتي**: `DualAccentAudioEngine` المبني على Android `TextToSpeech` مع اختيار أصوات اللهجة الأمريكية (`en-US`) والبريطانية (`en-GB`) وتخصيص طبقة وسرعة الصوت لـ 22 شخصية بشرية.
